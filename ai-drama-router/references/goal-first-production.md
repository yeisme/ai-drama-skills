# 从用户目标选择制作路径

## 先理解这轮要做什么

先读当前请求、已选方案与已确认约束，判断用户要验证什么、给谁看、希望得到什么成果。不要因为用户说“做剧”，就默认要建长期角色资产库；不要因为用户说“最新模板”，就执行模板包全部槽位。

优先提取：故事或动作的验证目标、交付用途、单集/多集与时长、已有剧本和图片、身份保持程度、是否需要多次复用。预算与时间只使用用户提供的事实，不猜测。缺费用授权时由执行 owner 处理，创作问题不能代替费用授权。

只有信息缺失且会改变方案时才问。建议一个问题：“这轮主要想先看故事/动作效果、完成一集，还是建立以后反复使用的人物资产？”把符合上下文的路线放在首位。用户已说“只做一集展示一镜到底”，直接采用动作验证路线，不再问同一个选择。不默认启动长访谈；需要时再问最关键的身份保持或交付约束。

## 按目标选择必要资产

| 目标 | 首轮交付 | 必要检查 | 可后置工作 |
| --- | --- | --- | --- |
| 故事探索、剧本吸引力 | 大纲、核心场景、对白与结尾 | 人物目标、冲突、因果和观众理解 | 未请求的图片与视频 |
| 快速视觉/动作 demo | 每人一张全身定妆照、一个开场构图、短动作测试 | 人数、身份、服装、道具、动作与空间连续性 | 六视图、表情库、拆层、透明背景 |
| 单集完整成片 | 已选视觉参考、覆盖剧情的镜头方案、声音与完整候选 | 剧情可读、声画同步、连续性、规格与交付接受 | 本集不用的服装/场景变体 |
| 多集稳定生产 | 代表集试片、跨集连续性记录、实际会复用的角色/场景包 | 跨集身份、服装状态、版本和复用证据 | 未验证需求的全量资产扩充 |
| 模块化资产库或精确合成 | 分层设计、所需独立视图、接口和透明输出 | 拆层、真实 alpha、版本、材质与重组一致性 | 不属于交付范围的剧集生成 |

这些是工作路线，不新增机器枚举、状态或默认全局策略。把选择及理由写入现有目标、交付说明和阶段 handoff；结构化状态仍由宿主命令维护。

## 快速 demo 的推进顺序

1. 沿用用户认可的剧情与导演方向。先列出这轮真正要测试的动作；不要用出图数量衡量进展。
2. 复用可用且有权限的脸图作身份参考，每人先准备一张同一套服装的三分之四角度全身定妆照。普通背景允许，透明通道仅在用户要合成或资产交付时成为要求。
3. 若人工需要核对服装，可提供每人正面、侧面、背面的完整定妆三视图。它是审阅图，不是三个角色，也不等于三个独立资产已通过。视频优先使用清晰单视图；必要时经图像 owner 提取并登记派生来源，不直接塞整张三视图导致人数混淆。三视图不是开拍前的通用硬门。
4. 多人场景优先完成一个开场构图，统一人物站位、门桌关系、道具归属、光线与行动通路。人物参考分别绑定身份和服装，场景参考只绑定布局与光线。只提供当前时点应该出现的剧情信息，避免提前露出线索。
5. 在模型支持的时长内先做短动作测试；例如5秒检查抓袖、递盒、手臂归属、人物数量与身份、道具及空间连续性。模型不支持5秒时采用最近可用时长并说明，不能伪造能力。静音诊断须明确关闭或处理音频。
6. 测试通过后再推进30秒或用户所需完整时长。一次生成成功、静态图好看或声音连续均不能证明一镜到底；检查跳切、全遮挡掩盖接缝、瞬移、换脸、道具复制和空间变化。

候选/实验与正式生产仍分开。快速路线不会自动接受资产、冻结主体或绕过执行 owner 的准入；若正式镜头入口尚未满足要求，只使用 owner 实际支持的非生产实验入口，并如实说明验证范围。不要把实验结果宣称成可发布成片。

## 根据用途选择参考图生成或严格编辑

定妆、换姿态、换构图、多人组合和场景重构通常需要“参考图指导新图”，不要求逐像素保留原画布。精确蒙版、受保护区域和局部修补才需要严格编辑。意图与具体接口由图像执行 owner 映射，不能把“有参考图”一律理解成编辑接口。

严格编辑明确不可用时，如果用户已允许整体重绘，可保留所有参考图转为参考图生成，不重复询问。没有该授权且会损失明确的保持要求时，先简短说明影响并问一次。用户允许参考图生成，不代表允许丢弃参考图改纯文生图，也不代表允许更换模型、增加成本上限或扩大批次。

HTTP 500 是请求失败证据，不能单独证明编辑或透明能力不支持。保存失败运行和来源，区分“事实：请求失败”“未知：具体原因”“方案：允许的替代路线”。参考图生成同样需要真实图片输入能力；仅检查模型名称或凭据不算通过。

## 路由自查场景

| 输入 | 应选路线 | 不应发生 |
| --- | --- | --- |
| “只做一集，先展示一镜到底” | 定妆单视图→开场构图→短动作→完整候选 | 自动扩充十人全槽位或整季 |
| “给动画团队交付可拆装角色库” | 模块化资产与接口验证 | 用普通背景整人图冒充透明资产 |
| “先看看剧本有没有吸引力” | 核心场景试写与故事评审 | 先花费生成角色库 |
| “人物不能变，原图其他地方完全不动” | 严格编辑/保护要求 | 不经确认改为整体重绘 |
| “允许参考图重绘，不用透明背景” | 有序参考图生成、普通背景 | 再次询问同样授权，或静默删除参考图 |
| “多集长期复用，但今天先测试” | 今天做代表片段，保留后续复用要求 | 永久删除复用能力或今天全量建库 |
